# Intent 作品说明草稿

Intent 是面向第一次使用 AI 的人、尤其是长辈的日常助手。用户可以用一句话开始，阅读大字号结果，通过明确按钮回答问题、同意计划或拒绝购买建议。

本版使用 Meta Muse Spark 1.3 进行自然语言理解和工具选择。模型输出经过服务端工具参数校验，重要交互记录在独立的任务时间线中。礼品卡、汇款等禁做规则和预算限制由服务端执行，不能仅靠提示词。

已验证的真实模型场景包括：解释虚构诈骗短信的风险、生成生日祝福。桌面和手机自动化测试还覆盖计划确认、购买建议审批、预算变化、停止旧任务、语言字号切换和匿名会话隔离。这些自动化测试使用确定性模型，应与真实模型实测分别报告。

本次增量包括 Meta 接入、推理预算与空响应处理、签名匿名会话、跨站检查、审批执行边界、取消执行隔离、重启恢复、独立服务端构建和回归测试。此前已存在适老界面和任务流程原型，不能宣称整个项目是在活动期从零完成。

当前交付为单进程可运行原型，尚不包含真实付款、后台提醒、多设备账户和托管生产数据库。后续重点是与长辈开展可用性测试及完善生产部署。

正式提交前填入：参赛者和团队信息、经审查的源码地址、真实演示视频地址、部署或评审运行方式。不要用占位链接提交。
