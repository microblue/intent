## 0. 一页纸

**Intent 是给不会用 AI 的人的 AI 帮手。** 说一句想做什么，它帮你想清楚、做计划、在后台把事办了，需要你决定时才来问你。家里懂技术的人可以帮忙设置、一起看着，但做主的永远是你自己。

**为什么我们能做到行业第一：**
1. **大厂的 agent 都是给会用的人做的。** Claude Duet 明说面向专业人士和小老板；OpenAI dots 要 $100/月；Gemini Spark 首发在最贵的 Ultra 套餐；Meta Muse 注册就要绑卡，吉祥物偏年轻。没有一家把「65 岁、第一次用 AI」当成主要用户来设计。
2. **「家人一起看着」这件事，市场上是空白。** 所有 agent 的审批都只发给账号本人。唯一做过家人代管的 Amazon Alexa Together 已于 2025 年 5 月停掉；Loved、ElliQ 有家人圈，但它们不替人办事。「能办事的 agent + 家人这一层」，目前没有任何产品同时做到。
3. **防诈骗是老人用 AI 的最大心理门槛，而现有 agent 的审批都假设「点同意的人能做出正确判断」。** Intent 把「永远不做的事」和「新的收款方要告诉家人」做成默认设置，这是我们能公开承诺、别人很难跟进的地方。
4. **国际化，中英文从第一天就同等对待。** 大厂 agent 基本只有英文版；中文 agent（豆包、千问）被锁在国内生态里。Intent 面向全球，不局限于国内：海外华人家庭、美国本地家庭都是用户，界面和帮手都跟着用户的语言走。

**一句话判断标准：** 一个 65 岁、只会用微信发语音的人，第一次打开 Intent，不需要任何人教，60 秒内就能让它开始帮自己办一件事。做不到，就是设计没做好。

## 1. 用户

### 1.1 主要用户：「王阿姨」

- 63 岁，退休，住在美国加州，跟女儿家不在一个城市。
- 会用微信：发语音、视频通话、看朋友圈、偶尔转账。打字慢，不太会拼音。
- 没用过 ChatGPT。听说过 AI，觉得「是年轻人的东西」，也怕被骗。
- 要办的事：看病挂号和吃药提醒、给孙子挑生日礼物、计划回国探亲的机票、看懂保险和账单、学会用手机上的新功能、给社区活动写通知。
- 遇到不会的事，第一反应是问女儿。

### 1.2 第二用户：「小李」（王阿姨的女儿）

- 36 岁，上班族，有两个孩子。自己用 ChatGPT。
- 痛点：每周要远程帮妈妈处理好几件事，常常在电话里一步一步教；担心妈妈被骗；没时间。
- 想要：妈妈能自己把事办了；自己能知道进展，关键时刻能把关；但又不想让妈妈觉得被管着。
- **小李很可能是付钱的人，也是把 Intent 介绍给妈妈的人。**

### 1.3 第三用户：家长给孩子用

- 家长自己订阅后，可以给子女（包括未成年子女）开账号。
- 孩子的账号由家长管理：花钱一律要家长点头，「永远不做」清单更严，内容更保守。
- 13 岁以下（美国 COPPA）需要家长可核实的同意，账号只能由家长创建。

### 1.4 不是我们的用户（v1）

- 想要最强通用能力的人（他们会用 ChatGPT 和 Claude）。
- 企业和团队用户。
- 想自己写规则、搭自动化的人。

## 2. 设计原则（每一条都可以拿来否决方案）

1. **一屏一件事。** 每个画面只有一个最主要的动作。看不出该点哪里，就是设计失败。
2. **说话就行。** 语音是主通道，不是附加功能。每条回复都能一键朗读。
3. **它来找你，不用你找它。** 用户不需要记得去哪里看进展。需要你的时候它出现在首页最上面，不需要的时候安静。
4. **先说清楚再动手。** 先给计划，你同意了再做；花钱、联系别人之前一定先问；永远不做的事明确写出来。
5. **你做主，家人帮忙。** 家人能看、能帮着把关，但开不开、给谁看、看什么，由你决定。每一个动作都写明是谁做的。
6. **不说一个术语。** 不出现 AI、模型、agent、助手团队、节点、Markdown 这类词；不中英混排；不出现任何英文标签。
7. **大、稳、慢。** 默认大字、大按钮；界面布局不跳动；不设倒计时；任何操作都能撤回或者有人兜底。

## 3. 核心概念：「一件事」

用户面对的单位只有一个：**一件事**（例如「给孙子挑生日礼物」）。不叫项目、任务、对话、Intent。

### 3.1 一件事的生命周期

| 状态 | 用户看到的一句话（示例） | 下一步动作 |
|---|---|---|
| 刚说出来 | 「我想想需要问您什么…」 | — |
| 在问您 | 「还有 2 个小问题」 | 回答（点选项或说话） |
| 计划等您同意 | 「我打算这样做，您看行吗？」 | ［好，开始］［改一改］ |
| 在办 | 「正在比较 5 家店的价格，明天上午告诉您」 | 不需要动作（可以「先停一下」） |
| 等您点头 | 「找到 3 个合适的，您挑一个？」 | 卡片上的动作按钮 |
| 办完了 | 「礼物清单好了，最合适的是这个」 | ［看看结果］ |
| 帮您盯着 | 「价格降了我告诉您」 | 不需要动作 |
| 收起来了 | （不出现在首页） | 在「我的」里能找回 |

**规则：** 任何时候，每件事只有一句状态和最多一个需要用户做的动作。不显示进度百分比、步骤编号、时间线。

### 3.2 只有一个帮手

用户只面对一个帮手。后台怎么分工（查资料、比价、写东西）是我们的事，**界面上不出现任何「助手团队」「专家」「交给谁」**。

- 现有原型里的 12 个专家助手、助手选择器、「加助手」、按助手署名的回复，全部去掉。
- 帮手说话时自称「我」，并在第一次见面时说明「我是 AI，会尽力帮您，但有时也会出错，重要的事我都会先问您」。

### 3.3 帮手叫什么（需要拍板）

「Intent」作为品牌没问题，但对王阿姨来说，英文名不好念，也不好用语音叫。

- **已定**：帮手**不另起名字，就叫 Intent**，中英文都一样，自称「我」。
- 原因：「小 X」类名字几乎都被占了（华为小艺、小米小爱、百川百小应、SoundAI 小易），语音里也容易听混；产品国际化后，一个名字比两个名字好记。
- 用户不需要叫出帮手的名字：说话靠按住麦克风，不靠唤醒词。
- 以后可以允许用户自己起个昵称（v1.5）。

## 4. 信息架构

整个产品只有 **3 个地方**：

```
今天（首页）     一件事（详情）     我的
```

外加一个随时能叫出来的「说一件新事」。

### 4.1 被合并或删除的现有页面

| 现有页面 | 处理 | 原因 |
|---|---|---|
| 想做的事（首页） | 改成「今天」 | 首屏改为「等您点头」+「您的事」 |
| 正在做的事 / 通知 | 并入「今天」 | 同一件事的进展，现在有 4 个地方都在显示 |
| 提醒 | 并入「今天」的「接下来」和每件事的状态 | 提醒就是「帮您盯着」这件事的一部分 |
| 记得的事 | 移到「我的」 | 不是每天要看的东西 |
| 助手能做什么（17 行开关） | 移到「我的」，改成 3 个总开关 + 「永远不做」清单 | 17 行 × 3 档太密 |
| 帮助（11 个概念词汇表） | 改成「怎么用」：3 个 30 秒示范 | 用户要的是怎么用，不是系统怎么组织 |
| 底层引擎 | 删除，开发调试另做内部工具 | 普通用户永远不该看到 |
| 封存的 | 移到「我的」 | — |
| Cmd+K 搜索 | 保留为快捷方式，不再宣传，界面不显示快捷键提示 | 目标用户不用快捷键 |

### 4.2 导航

- **手机**：底部 3 个大格：「今天」「＋ 说一件事」（中间、凸起、最大）「我的」。
- **桌面**：左侧窄栏，内容同上；不再有「最近」列表、搜索框、选主机下拉框。
- 「等您点头」有内容时，「今天」上显示红点和数字。

## 5. 主要画面

> 尺寸统一按第 9 节的规格。下面的线框只表达结构和文案，不代表视觉稿。

### 5.1 今天（首页）

```
┌─────────────────────────────────────────┐
│  下午好，王阿姨                    [我的] │
│                                         │
│  ┌ 等您点头 (1) ───────────────────────┐ │
│  │ 🎁 给小宝挑生日礼物                  │ │
│  │ 找到 3 个合适的，您挑一个？          │ │
│  │ [ 看看这 3 个 ]                      │ │
│  └─────────────────────────────────────┘ │
│                                         │
│  您的事                                  │
│  ✈️ 回国机票     在帮您盯价格，降了告诉您 │
│  💊 降压药提醒   每天早上 8 点提醒您      │
│  📄 看懂医保信   办完了  [看看结果]       │
│                                         │
│  接下来                                  │
│  明天 8:00  吃降压药                     │
│                                         │
│        [ 🎤  说一件新的事 ]              │
└─────────────────────────────────────────┘
```

- **从上到下的顺序固定**：等您点头 → 您的事 → 接下来 → 说一件新的事。
- 「等您点头」没有内容时整块不出现，不显示「暂无」。
- 「您的事」每行只有：图标、名字、一句状态、最多一个按钮。不显示计数图标、封面大图、时间戳。
- 模板（「计划一次旅行」等）**不放首页**，放到「说一件新的事」里面。
- 第一次使用（还没有任何事）：首页就是第 6.1 节的欢迎画面。

### 5.2 说一件新的事

保留现有 `/new` 流程的骨架（审查认为是全产品做得最好的部分），做 4 处改进：

1. **默认是语音**：大麦克风按钮在正中，「按住说话」；下面才是打字框。
2. **例子按生活场景分组**，最多 6 个：看病吃药、买东西挑礼物、出门旅行、看懂文件账单、学用手机、给人写东西。
3. **追问最多 3 个，一次一个，每个都有 2–4 个大按钮选项**，也能直接说话回答、跳过，或者「先这样，直接开始」。
4. **计划卡**：「我打算这样做：① ② ③。大概明天上午给您结果。」按钮为［好，开始］［改一改］。

**修复 P0 问题**：追问的答案必须完整带进这件事。进入详情后，帮手不能再问一遍已经问过的问题，也不能改写用户的原话。

### 5.3 一件事（详情）

```
┌─────────────────────────────────────────┐
│ ← 今天       🎁 给小宝挑生日礼物          │
│ 正在比较价格，明天上午告诉您    [这件事 ▾] │
├─────────────────────────────────────────┤
│                                         │
│  （对话：大字、宽松，像微信聊天）          │
│  帮手的每条消息右下角：[🔊 读给我听]       │
│                                         │
│  ┌ 计划卡 ─────────────────────────────┐ │
│  │ ① 问清楚喜好 ✓                       │ │
│  │ ② 比较价格 ← 正在做                   │ │
│  │ ③ 给您 3 个选择                       │ │
│  └─────────────────────────────────────┘ │
│                                         │
│  ┌ 等您点头卡（见 7.2）─────────────────┐ │
│                                         │
├─────────────────────────────────────────┤
│ [🎤 按住说话]  或者打字…         [发送]   │
└─────────────────────────────────────────┘
```

- **只有对话一栏**。删除右侧 6 个可拖拽小窗：大纲、计划、文件、团队、记得、提醒。
- 计划、结果、等您点头，都以**卡片**形式出现在对话里，出现在它们发生的时间点。
- 顶部「这件事 ▾」展开一个抽屉，里面只有 4 项：
  1. 计划和进展
  2. 结果（文件、清单，用中文名，不带 `.md` 之类的后缀）
  3. 「我做了什么」时间线（每一步都写明是谁做的，第 7.4 节）
  4. 收起这件事 / 这件事办完了
- 帮手每条消息下方的出处说明保留，但改成人话：「我在 5 家店比了价格」，可以点开看是哪几家。不出现 Skyscanner、Booking 这类品牌名，除非用户点开。
- **「这不对」按钮**：长按或点某条消息旁的「⋯」→「这不对」，帮手会认错并给出改正方案。

### 5.4 我的

按使用频率排序：

1. **字大一点 / 字小一点**（放在第一位，3 档，立刻生效）
2. **家人帮手**（第 8 节）
3. **它记得我的事**（可以看、可以删；敏感信息默认不记，例如银行卡号、证件号、密码）
4. **它能替我做什么**（第 7.1 节：3 个总开关 + 「永远不做」清单）
5. **收起来的事**
6. **怎么用**（3 个 30 秒的示范）
7. **账号**（邮箱、语言、退出登录、删除我的所有数据）

## 6. 第一次使用

### 6.1 先用，后注册

```
你好，我是Intent。
您想让我帮您做什么？说一句就行。

        [ 🎤 按住说话 ]

    或者点一个试试：
    [ 💊 提醒我吃药 ]  [ 🎁 帮我挑礼物 ]
    [ ✈️ 查回国机票 ]  [ 📄 看懂一封信 ]

    ─────────
    [ 我的家人帮我设置 ]
```

- **不先注册**。打开就是一个匿名账号，直接能用。用户说完第一件事、看到第一份计划后，再提示：「要我开始办吗？我需要记住您，留个邮箱收一个验证码就好。」
- **v1 登录用邮箱 + 6 位验证码**（全球都能用，不需要短信通道），不用密码；加 Google 登录。手机号验证码、Apple 登录、微信登录在后续版本支持。验证码可以放大、有效期可以延长。
- 语言：第一次打开按浏览器语言选中文或英文，首页右上角一键切换。
- 不要求绑卡，不在注册时要求连接任何账号。

### 6.2 家人帮忙设置

- 小李在自己的手机上打开 Intent →「帮家人设置」→ 输入妈妈的名字和邮箱 → 可以先替妈妈准备好 1–3 件事（例如「每天 8 点提醒吃药」）。
- 妈妈手机收到一个链接，点开后看到：「您的女儿小李帮您准备好了Intent。小李想帮您一起看着这些事：［列出权限］。您同意吗？」［同意］［先不要，我自己用］。
- **必须由妈妈本人确认才生效**（研究显示，子女单方面开启的看护功能，老人拒绝率极高，也伤尊严）。

## 7. 信任和安全

### 7.1 三档规则（默认值）

| 档位 | 包括的事 | 怎么做 |
|---|---|---|
| **直接做** | 查资料、比价、做计划、起草文字、设提醒 | 不打扰，做完告诉您 |
| **先问您** | 花钱、替您联系别人（发消息、打电话、发邮件）、提交表格、删除东西 | 出现「等您点头」卡片；您不点，就不做 |
| **永远不做** | 转账给个人、买礼品卡或充值卡、改密码和安全设置、借钱、贷款、投资、炒股 | 帮手会直接说「这个我不做」，并告诉您原因；用户也无法打开 |

- 「它能替我做什么」页面只有 3 个总开关：**花钱**、**替我联系别人**、**看我的资料**（例如邮箱、日历），每个开关只有「先问我」和「不行」两档。现有原型的 17 行 × 3 档全部去掉。
- 「永远不做」清单在「我的」里明文列出，并在首次使用时告诉用户。**这是我们对用户的公开承诺。**

### 7.2 「等您点头」卡片

每张卡片必须回答 5 个问题：**做什么、给谁、花多少、为什么、能不能撤回**。

```
┌───────────────────────────────────────────┐
│ 🎁 给小宝挑生日礼物                          │
│                                           │
│ 我想帮您买：乐高城市消防站                   │
│        $49.99（含运费）                    │
│ 在：Target，3 天后送到您家                  │
│ 为什么选它：小宝 6 岁，喜欢消防车；           │
│            另外比较了 2 个，这个评价最好      │
│ 能不能退：30 天内可以退                      │
│                                           │
│ [ 不买了 ]            [ 好，买这个 ]         │
│            [ 看看另外 2 个 ]                │
└───────────────────────────────────────────┘
```

- 金额用最大的字号。
- 「拒绝」和「同意」一样大、一样醒目。按钮上写动作（「好，买这个」），不写「确认 / 取消」。
- **没有倒计时，不点就不做。** 一直没有回应的，帮手会在合适的时候换个方式再问一次。
- **v1 可以替您花钱**（DZ 已定），但每一笔都必须经过这张卡片，并受花费上限约束：
  - 每笔上限、每月上限由用户在「我的」里设，默认每笔 $100、每月 $300；超过上限的直接不做，并告诉用户怎么调。
  - 付款通道分两步上线：**第一步**，帮手把商品放好、把信息填好，带您到付款页，您自己点付款（今天就能做，商家都支持）；**第二步**，接入 agent 支付协议（如 Stripe/OpenAI 的 Agentic Commerce Protocol、Visa、Mastercard 的 agent 支付），用一次性的虚拟卡或支付令牌由帮手完成付款。帮手永远不保存、也看不到您的卡号和密码。
  - 新的收款商家第一次出现时，卡片上额外标出「第一次在这家买」。
- 已经发出的消息、已经提交的表格，10 分钟内可以撤回（参照工信部适老化规范）。做不到撤回的，卡片上提前写明「这一步做了就不能撤回」。

### 7.3 防诈骗

- **「这是不是骗子？」**：任何时候把可疑的短信、电话内容、链接发给Intent（转发、截图、说给它听），它会用大白话告诉您风险。这是新用户的第二个入口。
- 第一次出现**新的收款方、新的联系人**时，额外提醒一次；开了家人帮手的，同时告诉家人。
- 帮手**永远不会**主动向您索要密码、验证码、银行卡号。产品里写明：「如果有人自称Intent向您要这些，那一定是骗子。」

### 7.4 「我做了什么」

每件事都有一条用人话写的时间线：「10月25日 下午 3 点，我在 5 家店比了价格」「下午 4 点，您同意买乐高消防站」「下午 4 点 05 分，女儿小李看到了这件事」。

- 每个动作都写明是谁：Intent、您自己、家人（写名字）。
- 帮手出错时，先认错，再给补救方案：「我刚才看错了日期，正确的是 7 月 8 日，我已经帮您改好了。」

## 8. 家人帮手（核心差异化）

> v1 只做前两档（「要紧时告诉家人」「家人能看到进展」）；「帮我把关」「一起管」进 v1.5。

### 8.1 四档权限

| 档位 | 家人能做什么 | 默认 |
|---|---|---|
| **只在要紧的时候告诉我家人** | 发生异常（新收款方、疑似诈骗、几天没打开）时通知家人；家人看不到具体的事 | |
| **家人能看到进展** | 看到每件事的名字、状态、结果；看不到对话原文 | ✅ 默认 |
| **家人能帮我把关** | 在您设定的范围内（例如超过 $100 的花钱）替您点头，或者和您一起点头 | |
| **家人和我一起管** | 能替您新建和修改事情 | |

- **只有用户本人能升档**，家人发出申请，本人点同意才生效；本人随时可以降档或暂停。
- 「我的 → 家人帮手」一眼能看到：谁、能看到什么、最近看了什么。有一个大按钮「暂时不让家人看」。
- 文案用「帮忙」「一起看」，不用「监控」「管理」「授权」。

### 8.2 家人把关怎么工作

1. 王阿姨要买一个 $150 的东西，超过她设的 $100 →
2. 王阿姨和小李同时收到「等您点头」卡片 →
3. 任何一方点了「好」→ 继续；任何一方点了「不买了」→ 停止 →
4. 结果写进时间线：「女儿小李同意了」，并告诉王阿姨。

**家人永远用自己的账号**，不共享密码，不冒充本人。

### 8.3 家人这一端看到什么

小李的「今天」首页多一块「家人的事」：

```
妈妈（王阿姨）
  等您一起点头：给小宝买生日礼物 $150  [看看]
  本周办完：看懂医保信、订好复诊
```

## 9. 视觉和适老规格

| 项目 | 规格 | 依据 |
|---|---|---|
| 正文字号 | 默认 20px（桌面）/ 18pt（手机）；3 档可调，最大档 ≥ 30 | 工信部 APP 适老规范：≥18，最大可调 ≥30 |
| 行距 | ≥ 1.5 倍 | 规范要求 ≥1.3 |
| 对比度 | 正文 ≥ 7:1（WCAG AAA） | WCAG；规范要求 ≥4.5:1 |
| 主要按钮 | ≥ 60×60，大多数 ≥ 64 高 | 工信部：主要组件 ≥60×60 |
| 其他可点区域 | ≥ 48×48 | Material 48dp、Apple 44pt |
| 最小字号 | 任何地方不小于 16px；去掉现有原型里所有 11–12px 的小字 | 审查发现大量 11px 文字 |
| 手势 | 只用点击；不依赖滑动、长按、多指（长按「这不对」另有点击入口） | 工信部 |
| 时限 | 不设倒计时；验证码可延长 | 工信部 |
| 广告 / 诱导按钮 | 0 | 工信部 |
| 动效 | 只用于状态变化，可关闭；布局不跳动 | W3C WAI-AGE |
| 等待反馈 | 1 秒内要有反应；超过 10 秒显示「大概多久」，并可以离开 | NN/g |
| 文案 | 一句一事，小学高年级能读懂；不中英混排，没有英文标签 | CDC 清晰沟通指数 |
| 颜色 | 暖色、柔和、亲切；红色只用于「永远不做」和诈骗警告 | — |

**适老是默认界面，不是一个「长辈模式」开关。** 能熟练使用老年模式的老人只有 9.5%，藏在开关后面就等于没有。年轻用户（家人一端）可以调小字号。

## 10. 帮手怎么说话

1. **称呼**：默认称「您」；用户可以说「叫我王姐就行」。
2. **长度**：每条回复先说结论，3 句以内；需要细节的折起来，「想看细节点这里」。
3. **追问**：一次只问一个；每个问题都给选项；最多问 3 个；能自己判断的不问。
4. **计划**：最多 5 步，每步一句人话，写明大概什么时候有结果。
5. **进度**：只在 3 种时候主动说话：需要您决定、办完了、卡住了。不汇报「我正在思考」。
6. **不确定时**：说出来，「这个我不太确定，建议您跟医生确认一下」。健康、法律、大额的事，结果后面固定加一句建议找人确认。
7. **出错时**：先认错，再说怎么改，再说已经改了什么。
8. **语气**：温和、耐心，但不啰嗦、不讨好、不装可爱；紧急的事（疑似诈骗）直接、清楚。
9. **从不**：说术语；假装是人；向用户要密码、验证码、卡号；替用户做「永远不做」清单里的事。
10. **听出用户不满**：用户说「不对」「不是这个」或者换个说法重问，帮手要意识到自己理解错了，主动换方向，不要重复原来的回答。

## 11. 它会主动找您吗？

- **默认只在 3 种时候找您**：需要您点头、事情办完、事情卡住了。
- **每天的小结是可选的**，由用户自己开：「要不要我每天早上 8 点告诉您今天的事？」（教训：OpenAI 不请自来的每日卡片 Pulse 据报道已经下线，用户自己订阅的简报才留得住。）
- **v1 的通知渠道**：App 内红点、浏览器/手机推送、邮件。短信和微信在后续版本接入。
- 主动提醒之前先征得同意，并说明原因：「要不要我每天 8 点提醒您吃降压药？您上次说常常忘。」

## 12. v1 能办的事（范围）

**v1 做：查、比、想、写、记、盯**

| 类别 | 例子 |
|---|---|
| 查和比 | 比机票、比礼物、找附近的医生、查药的副作用 |
| 做计划 | 旅行行程、一周菜单、生日聚会 |
| 写东西 | 给医生的留言、社区通知、给孙子的生日祝福、看不懂的信件翻译和解释 |
| 记和提醒 | 吃药、复诊、续保、缴费 |
| 帮您盯着 | 价格降了告诉您、预约有空位告诉您 |
| 防诈骗 | 「这是不是骗子？」 |
| 教用手机 | 一步一步的大字图文教程 |

**v1 也做：替您花钱**（每笔都要您点头，有上限，见 7.2）。

**v1 不做：替您对外发消息、连接您的邮箱和日历、短信通知。** 需要联系别人时，帮手把消息写好，您自己发。

- 第 7 节的审批机制和第 8 节的前两档家人权限在 v1 就要做出来。
- 开发期所有角色都用最便宜的模型 Claude Haiku 5.5，上线前按角色评测再决定要不要升级。

## 16. DZ 拍板结果（2026-10-25）

1. **名字**：不用「小 X」（撞名）。帮手就叫 Intent，不另起名。
2. **v1 范围**：可以替人花钱；开发期用最便宜的 Haiku 5.5。对外发消息仍不做。
3. **市场**：不限定，做国际化产品，中文、英文都支持，不局限于国内。
4. **家人帮手**：v1 做前两档。
5. **付费**：先各付各的，不做家庭套餐；家长订阅后可以给子女（含未成年）用。
6. **流程**：设计定稿，开始开发。
